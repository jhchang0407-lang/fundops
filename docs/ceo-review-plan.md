## Vision

### 10x Check
The 10x version: FundOps becomes the "Hugging Face of investment research." An open-source agent framework where a community of fund managers contributes agents, connectors, and strategy presets. Self-improving agents learn each user's style. A marketplace of custom Scout lenses, Val models, and Judge rubrics. Every fund runs FundOps, every fund's agents get smarter from the collective outcome data (anonymized).

### Delight Opportunities
1. Demo mode with sample data (try before configuring)
2. One-click pipeline run (Scout through Judge in one button)
3. Visual research timeline per ticker
4. Export pipeline results as clean PDF/markdown
5. CSV portfolio import in setup wizard
