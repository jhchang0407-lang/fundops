## Problem Statement

The Library (formerly Ledger) is the institutional memory of FundOps. Right now it's a directory scanner that dumps memos into a JSON registry and tracks price returns vs SPY. It's disconnected from the pipeline (other agents don't query it), has no outcome tracking (did we act on the research?), no bias detection (what patterns of wrongness do we repeat?), and no way for users to browse or search their research.

The Library sits at the intersection of every other agent. Scout needs to know "we researched this before." Judge needs to know "last time we evaluated a similar company, we were wrong about X." The Allocator needs to know "these passed memos are still in the opportunity library." Without the Library working properly, every agent operates without memory. The system can't learn.

## What Makes This Cool

Three things no other open-source investment tool does:

1. **The Autopsy Engine.** Every archived thesis has falsifiable assumptions (from Judge) and predicted return sources (from Val). The Library periodically checks: did those assumptions hold? Was the return decomposition right? Over time, it builds a systematic bias profile: "We consistently overestimate margin expansion in retail." "Our bear cases on SaaS companies are 15% too optimistic." This gets fed back to Judge and Val. The system literally learns from its own mistakes.

2. **Agent Memory.** When Scout surfaces CHKP again in 6 months, it doesn't start from zero. It gets: "We researched CHKP 6 months ago. Thesis: quality-under-fear cash cow. IC verdict: PASS. The stock is up 35% since. 4 of 5 assumptions still intact. Our margin expansion prediction was slightly optimistic." One function call: `get_library_context("CHKP")`.

3. **Browsable Knowledge Base.** Users can search all their research by ticker, sector, strategy type, date range, outcome. Every piece of research the system ever produced, organized and retrievable. With semantic search so you can ask "show me all the times we invested in undervalued SaaS companies" and get results.

## Constraints

- **Storage:** SQLite is fine for single-user. The documents table already exists. Extend, don't replace.
- **Performance tracking cost:** Free (yfinance for prices). Run weekly.
- **Post-mortem cost:** ~$0.05/thesis for LLM comparison of predicted vs actual. Run monthly or on-demand.
- **Semantic search:** Requires embeddings. One-time cost to embed all existing memos, then incremental on new arrivals. ~$0.01/memo for embedding.
- **Cold start:** Bias detection and ML calibration are disabled until 50+ post-mortems accumulate. The schema and autopsy engine run from day one, building the data. The learning system activates automatically once the threshold is met. No false signals from small samples.
- **NOT a screener.** The Library never recommends, ranks, or screens. It stores, retrieves, tracks, and reports.

## Premises

1. The Library is a passive filing cabinet, NOT a screener. It stores, retrieves, tracks performance, and provides feedback to other agents. It never recommends.
2. Everything from the pipeline gets archived automatically via event-driven hooks. No directory scanning.
3. Outcome tracking closes the loop: did we buy it, did we pass, what happened either way.
4. Performance tracking is automatic and benchmark-relative from memo date.
5. The Library feeds other agents with historical context (the feedback loop).
6. Organization is tags + semantic search. Users can browse all research.

#### 1. Data Model

```python

    shares: float | None
```

#### 2. Event-Driven Archival

Replace directory scanning with direct calls. When any agent script completes, it calls `LibraryIngest` at the end of its run. There is no event bus or pub/sub system. Each agent simply imports and calls the ingest function. The daily `library-archive-sweep` cron is the catch-all for anything the direct calls missed (e.g., memos generated outside the pipeline).

```python
class LibraryIngest:
    """Ingests pipeline output into the Library."""

    async def on_thesis_complete(self, ticker: str, thesis_output: dict):
        """Val completes a thesis → archive it."""
        doc = ArchivedDocument(
            ticker=ticker,
            doc_type="thesis",
            source_agent="val",
            title=f"{ticker} — Thesis",
            synopsis=thesis_output.get("summary", ""),
            content=json.dumps(thesis_output),
            tags=self._auto_tag(ticker, thesis_output),
            return_sources=self._extract_return_sources(thesis_output),
            assumptions=self._extract_assumptions(thesis_output),
            price_at_memo=thesis_output.get("current_price"),
            fair_value_at_memo=thesis_output.get("fair_value"),
        )
        await self._save_and_embed(doc)

    async def on_ic_complete(self, ticker: str, ic_output: dict):
        """Judge completes IC review → archive the verdict."""
        doc = ArchivedDocument(
            ticker=ticker,
            doc_type="ic_review",
            source_agent="judge",
            ic_verdict=ic_output.get("verdict"),
            # ... extract assumptions, return sources from IC output
        )
        await self._save_and_embed(doc)

    async def on_memo_complete(self, ticker: str, memo_output: dict, memo_type: str):
        """Memo agent completes → archive both research and investment memo."""
        doc = ArchivedDocument(
            ticker=ticker,
            doc_type=memo_type,  # "research_memo" or "investment_memo"
            source_agent="memo",
            content=memo_output.get("content", ""),
            # ...
        )
        await self._save_and_embed(doc)

    def _auto_tag(self, ticker: str, data: dict) -> list[str]:
        """Generate tags from content: sector, strategy lens, thesis bucket, etc."""
        tags = []
        if data.get("sector"): tags.append(f"sector:{data['sector']}")
        if data.get("thesis_bucket"): tags.append(f"bucket:{data['thesis_bucket']}")
        if data.get("strategy_lens"): tags.append(f"lens:{data['strategy_lens']}")
        return tags

    async def _save_and_embed(self, doc: ArchivedDocument):
        """Save to DB and generate embedding for semantic search."""
        self.db.insert_document(doc)
        # Generate embedding from synopsis + key content
        embedding = await self.embedder.embed(
            f"{doc.ticker} {doc.synopsis} {' '.join(doc.tags)}"
        )
        self.db.update_embedding(doc.id, embedding)
```

#### 3. Performance Tracking

Weekly cron job. Pulls prices for every archived ticker, computes returns, compares to SPY.

```python
async def update_performance(db, yfinance):
    """Weekly: update returns for all archived tickers."""
    tickers = db.get_all_archived_tickers()
    spy_prices = await yfinance.get_price_history("SPY")

    for ticker in tickers:
        docs = db.get_documents_for_ticker(ticker)
        current_price = await yfinance.get_current_price(ticker)

        for doc in docs:
            if not doc.price_at_memo:
                continue

            return_pct = (current_price - doc.price_at_memo) / doc.price_at_memo * 100

            # SPY return over same period
            spy_at_memo = _get_spy_price_on_date(spy_prices, doc.created_at)
            spy_now = spy_prices[-1]["price"]
            spy_return = (spy_now - spy_at_memo) / spy_at_memo * 100

            alpha = return_pct - spy_return

            db.update_document_performance(doc.id, current_price, return_pct, alpha)

            # Also write to performance_snapshots for time-series
            db.insert_performance_snapshot(
                ticker=ticker,
                doc_id=doc.id,
                snapshot_date=today,
                price=current_price,
                return_pct=return_pct,
                alpha_pct=alpha,
            )
```

#### 4. Outcome Tracking

Outcomes can be recorded three ways:

**Path 1: Auto-detect from Portfolio.** When the user imports a portfolio CSV, cross-reference against the Library. If CHKP is in the portfolio and CHKP has an archived thesis, auto-link: outcome = "bought" with the portfolio's cost basis.

**Path 2: Pipeline event.** When the allocator recommends "buy CHKP" and the user confirms, the outcome is recorded automatically.

**Path 3: Manual.** User clicks "Record outcome" on any archived research in the Library page. Simple form: bought/passed/watchlisted, price, date, notes.

**Counterfactual tracking for passes:** When the user passes on a name (IC says NO_PASS, or user declines), the Library still tracks what would have happened. "We passed on FISV at $57. It's now $92. +61% return, +43% alpha vs SPY." This is the most valuable training signal: the ones you passed on that worked.

```python
class OutcomeTracker:
    async def auto_link_portfolio(self, portfolio_holdings: list[dict]):
        """Cross-reference portfolio with Library to auto-record outcomes."""
        for holding in portfolio_holdings:
            ticker = holding["ticker"]
            docs = self.db.get_documents_for_ticker(ticker)
            for doc in docs:
                if doc.outcome is None:
                    self.db.update_outcome(doc.id, Outcome(
                        action="bought",
                        action_date=holding.get("purchase_date"),
                        buy_price=holding.get("avg_cost"),
                        shares=holding.get("shares"),
                        current_status="held",
                    ))

    async def track_passes(self):
        """For all verdicts without outcomes after 90 days, record as 'passed'."""
        # NO_PASS verdicts
        no_pass_docs = self.db.get_documents_where(ic_verdict="NO_PASS", outcome=None)
        for doc in no_pass_docs:
            self.db.update_outcome(doc.id, Outcome(
                action="passed",
                action_date=doc.created_at,
                current_status="never_bought",
            ))

        # PASS verdicts that the user never bought (after 90 days)
        pass_no_buy = self.db.get_documents_where(
            ic_verdict="PASS", outcome=None,
            created_before=datetime.utcnow() - timedelta(days=90),
        )
        for doc in pass_no_buy:
            # Check if it's in the portfolio
            if not self.db.ticker_in_portfolio(doc.ticker):
                self.db.update_outcome(doc.id, Outcome(
                    action="passed_despite_approval",
                    action_date=doc.created_at,
                    current_status="never_bought",
                    notes="IC approved but user did not buy within 90 days",
                ))
```

#### 5. The Autopsy Engine (Post-Mortem Diffs)

Monthly (or on-demand): for each archived thesis with outcome data and 3+ months of history, compare predicted vs actual.

```python
class AutopsyEngine:
    """Compares predicted return sources and assumptions against reality."""

    async def run_autopsy(self, doc: ArchivedDocument) -> PostMortemReport:
        """Generate a structured post-mortem for one archived thesis."""

        # Get actual financials for the period since memo
        actuals = await self._fetch_actual_metrics(
            doc.ticker, doc.created_at, today
        )

        # Compare total return: predicted vs actual
        # NOTE: Source-level return attribution (how much came from discount closing
        # vs margin expansion vs growth) is a research-grade problem. MVP autopsies
        # track TOTAL return predicted vs actual + per-assumption status checks.
        # Source-level attribution is approximate (LLM-estimated from financial data).
        actual_total_return = (actuals["current_price"] - doc.price_at_memo) / doc.price_at_memo * 100

        # Check each assumption against actual data
        assumption_results = []
        for assumption in (doc.assumptions or []):
            result = await self._check_assumption(assumption, actuals)
            assumption_results.append(result)

        # LLM generates a narrative summary (structured output)
        narrative = await self.llm.generate(
            prompt=AUTOPSY_PROMPT.format(
                ticker=doc.ticker,
                thesis_synopsis=doc.synopsis,
                predicted_returns=doc.return_sources,
                actual_returns=return_diff,
                assumption_results=assumption_results,
                price_at_memo=doc.price_at_memo,
                current_price=doc.current_price,
            ),
            response_format=PostMortemReport,
        )

        return narrative

class PostMortemReport(BaseModel):
    ticker: str
    memo_date: str
    review_date: str
    predicted_total_return: float
    actual_total_return: float
    return_source_diffs: list[ReturnSourceDiff]  # per source: predicted vs actual
    assumptions_right: list[str]   # assumption keys that held
    assumptions_wrong: list[str]   # assumption keys that broke
    biggest_miss: str              # one-line: what was most wrong
    biggest_hit: str               # one-line: what was most right
    lesson: str                    # one-line: what should the system learn

class ReturnSourceDiff(BaseModel):
    source: str         # "discount_closing" | "excess_growth" | "margin_expansion" | "dividends"
    predicted_pct: float
    actual_pct: float
    delta_pct: float    # actual - predicted (positive = underestimated)
    explanation: str    # why the delta
```

#### 6. Bias Detection (the Learning System)

Aggregate post-mortem data across all archived theses to detect systematic patterns.

```python
class BiasDetector:
    """Finds systematic patterns in prediction errors."""

    async def compute_bias_profile(self) -> BiasProfile:
        """Analyze all post-mortems to find repeating error patterns."""
        all_autopsies = self.db.get_all_post_mortems()

        if len(all_autopsies) < 50:
            return BiasProfile(
                sufficient_data=False,
                message=f"Need 50+ post-mortems for bias detection. Have {len(all_autopsies)}. "
                        f"Bias learning is disabled until enough data accumulates.",
            )

        # Aggregate return source diffs by category
        by_sector = defaultdict(list)
        by_lens = defaultdict(list)
        by_source = defaultdict(list)

        for autopsy in all_autopsies:
            sector = autopsy.tags.get("sector", "unknown")
            lens = autopsy.tags.get("lens", "unknown")
            for diff in autopsy.return_source_diffs:
                by_sector[sector].append(diff)
                by_lens[lens].append(diff)
                by_source[diff.source].append(diff.delta_pct)

        # Compute mean bias per category
        biases = []
        for source, deltas in by_source.items():
            mean_delta = sum(deltas) / len(deltas)
            if abs(mean_delta) > 3.0:  # 3% threshold for "systematic"
                dir_label = "overestimate" if mean_delta < 0 else "underestimate"
                biases.append(Bias(
                    type="return_source",
                    category=source,
                    direction=dir_label,
                    magnitude_pct=abs(mean_delta),
                    sample_size=len(deltas),
                    description=f"Systematically {dir_label} {source} by ~{abs(mean_delta):.1f}%",
                ))

        # Sector-specific biases
        for sector, diffs in by_sector.items():
            # ... same pattern, check if errors cluster by sector

        return BiasProfile(sufficient_data=True, biases=biases)

class BiasProfile(BaseModel):
    sufficient_data: bool
    message: str | None
    biases: list[Bias]
    generated_at: str
    sample_size: int        # total post-mortems analyzed

class Bias(BaseModel):
    type: str               # "return_source" | "assumption" | "sector" | "strategy_lens"
    category: str           # e.g. "margin_expansion" or "technology_saas"
    direction: str          # "overestimate" | "underestimate"
    magnitude_pct: float    # how wrong on average
    sample_size: int
    description: str        # human-readable
```

**How biases feed back to other agents:**

- **Judge:** When stress-testing return sources, if the Library has a bias of "we overestimate margin expansion by 5%," Judge automatically applies an extra haircut to margin expansion assumptions. This is injected into the IC review prompt.
- **Val:** When building the thesis, if the Library shows "we underestimate growth in SaaS companies," Val adds a note: "Library suggests we may be conservative on growth for this sector."
- **Scout:** When scoring candidates, Library context tells Scout "we researched this 6 months ago and the thesis was wrong because of X."

```python
def get_bias_adjustments(ticker: str, sector: str, strategy_lens: str) -> dict:
    """Returns bias adjustments for other agents to consume."""
    profile = db.get_latest_bias_profile()
    if not profile or not profile.sufficient_data:
        return {}

    adjustments = {}
    for bias in profile.biases:
        if bias.type == "return_source":
            adjustments[f"bias_{bias.category}"] = {
                "direction": bias.direction,
                "magnitude_pct": bias.magnitude_pct,
                "recommendation": f"Adjust {bias.category} estimates by {bias.magnitude_pct:.1f}% "
                                  f"({'down' if bias.direction == 'overestimate' else 'up'})",
            }
    return adjustments
```

#### 7. Semantic Search

Embed all archived documents for natural language search across the entire research base.

```python
class LibrarySearch:
    """Search the Library by ticker, tags, date, or natural language."""

    async def search(self, query: str, filters: dict = None) -> list[SearchResult]:
        """Hybrid search: exact match on ticker/tags + semantic on content."""

        results = []

        # Exact matches (fast, SQL)
        if filters:
            results += self.db.filter_documents(
                ticker=filters.get("ticker"),
                sector=filters.get("sector"),
                doc_type=filters.get("doc_type"),
                date_from=filters.get("date_from"),
                date_to=filters.get("date_to"),
                tags=filters.get("tags"),
            )

        # Semantic search (embedding similarity)
        if query and not query.upper().isalpha():  # not just a ticker symbol
            query_embedding = await self.embedder.embed(query)
            semantic_results = self.db.vector_search(
                query_embedding, top_k=20
            )
            results += semantic_results

        # Deduplicate and rank
        return self._rank_and_dedupe(results)

    async def ask(self, question: str) -> str:
        """Natural language question over the Library.

        'What did we learn about SaaS companies with declining growth?'
        'Show me all the times we were wrong about margin expansion.'
        'What's our track record on cybersecurity stocks?'
        """
        relevant_docs = await self.search(question)
        context = self._format_context(relevant_docs[:10])

        answer = await self.llm.generate(
            prompt=f"""You are a research librarian for an investment fund.
            Answer this question using ONLY the archived research below.
            If the research doesn't cover this topic, say so.

            Question: {question}

            Archived research:
            {context}""",
            reasoning_effort="medium",
        )
        return answer.text
```

**Embedding provider:** OpenAI `text-embedding-3-small` ($0.02/1M tokens, ~$0.001 per memo). For 100 memos = $0.10 total. Embeddings stored in SQLite (as JSON arrays) with a simple cosine similarity search. If scale grows past 1000 documents, migrate to a vector DB.

#### 8. Agent Context Interface

The single function other agents call to get Library context:

```python
async def get_library_context(ticker: str, requesting_agent: str = None) -> LibraryContext:
    """Everything the Library knows about a ticker.

    Called by:
    - Scout: "Have we researched this before? What happened?"
    - Judge: "What's our track record on similar companies?"
    - Val: "Any prior thesis we can build on?"
    - Allocator: "Is this in the opportunity library?"
    """
    docs = db.get_documents_for_ticker(ticker)
    post_mortems = db.get_post_mortems_for_ticker(ticker)

    # Look up sector and strategy lens from the latest document metadata
    latest_doc = docs[0] if docs else None
    sector = (latest_doc.tags or [None])[0] if latest_doc else None  # first tag is usually sector
    strategy_lens = db.get_active_strategy_lens()
    bias_adjustments = get_bias_adjustments(ticker, sector, strategy_lens)

    similar = await search.search(f"companies similar to {ticker}", top_k=5) if search else []

    return LibraryContext(
        ticker=ticker,
        researched_before=len(docs) > 0,
        documents=docs,
        latest_thesis=_get_latest_by_type(docs, "thesis"),
        latest_ic_verdict=_get_latest_by_type(docs, "ic_review"),
        latest_memo=_get_latest_by_type(docs, "investment_memo"),
        performance_since_research=_get_performance(docs),
        outcome=_get_outcome(docs),
        post_mortems=post_mortems,
        bias_adjustments=bias_adjustments,
        similar_research=similar,
        lessons_learned=[pm.lesson for pm in post_mortems if pm.lesson],
    )

class LibraryContext(BaseModel):
    ticker: str
    researched_before: bool
    documents: list[ArchivedDocument]

    latest_ic_verdict: ArchivedDocument | None

    outcome: Outcome | None
```

#### 10. Settings

- Update frequency (weekly/daily)
- Track counterfactual passes (on/off, on by default)

**Post-Mortem / Bias Detection:**
- Auto-run post-mortems after N months (default: 3)

#### 13. Scheduling

Three scheduled jobs:

- **`library-archive-sweep`**: Daily. Checks pipeline output for new documents not yet archived. Fallback for any events the hooks missed.
- **`library-performance-update`**: Weekly (Sunday). Updates all performance metrics and snapshots.
- **`library-autopsy-batch`**: Monthly (1st of month). Runs post-mortems on all theses with 3+ months of history. Regenerates bias profile.

#### 14. Error Handling

- **Embedding API fails:** Documents are archived without embeddings. Semantic search degrades to keyword search. Retry embedding on next sweep.
- **Price data unavailable:** Skip performance update for that ticker. Log warning. Retry next cycle.
- **Delisted/acquired tickers:** If yfinance returns no data for 3 consecutive weekly checks, mark the document as `tracking_stopped` with reason ("delisted", "acquired", "ticker_changed"). Exclude from future performance sweeps. Record final known price as the last data point.
- **LLM fails for post-mortem:** Flag document as "autopsy_pending". Retry next batch.
- **Insufficient data for bias:** BiasProfile returns `sufficient_data=false` with a message. No adjustments injected into agents. No false signals.

## Open Questions

1. **Embedding storage at scale.** SQLite with JSON arrays works for <1000 docs. At what point do we need pgvector or a dedicated vector DB? Probably not soon for a single user.
2. **Bias profile confidence intervals.** With 15 post-mortems, a "we overestimate margin expansion by 5%" claim has wide confidence intervals. Should we show confidence alongside bias magnitude?
3. **Multi-user Library.** If FundOps becomes multi-user, does each user have their own Library? Shared? Both?
