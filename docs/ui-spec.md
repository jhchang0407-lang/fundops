## Page 1: Pipeline Status Bar (global, always visible)

**Purpose:** CI/CD dashboard for the investment pipeline. Shows system health at a glance.

**Location:** Fixed bar above main content, 32px height, `--bg-secondary` background.

**Elements:**

| Element | Data Source | Display | States |
|---------|-----------|---------|--------|
| Screener status | `agent_runs` table, latest screener run | "Screener: 3d ago" or "Running..." | idle (muted text), running (amber pulse), stale (>7d, red text) |
| Thesis count | `agent_runs` where agent=thesis | "Thesis: 15/20" | count/total from last batch |
| IC count | `agent_runs` where agent=ic_review | "IC: 8 passed" | pass count from last batch |
| Memo count | `agent_runs` where agent=memo | "Memo: 3 ready" | count of IC-passed awaiting memo |
| Alert count | portfolio alerts | "Alerts: 2" | 0 = hidden, 1+ = amber badge, 3+ = red badge |
| Cost MTD | `learning_events` cost tracking | "$47 / $100" | progress bar, amber at 80%, red at 100% |

**Empty state:** "No pipeline activity yet. Run your first screen in Settings."

## Conversation Panel (global, collapsible sidebar)

**Purpose:** The natural language interface. Settings refinement + pipeline control + ad-hoc queries.

**Location:** Right side of main content, 320px wide, collapsible.

**Toggle:** Floating button (bottom-right) or keyboard shortcut (Cmd+J).

**Modes (auto-detected from intent):**
1. Strategy refinement: "I care more about capital allocation"
2. Agent profile mutation: "Make my memos focus more on valuation"
3. Pipeline query: "Run thesis on GOOGL", "What if I sell PAYC?"
4. Learning query: "What has the system learned?"
5. General: "How does the screener work?"

**Elements:**
- Message list (scrollable, newest at bottom)
- Text input with send button
- Current context indicator: "Talking about: Strategy" or "Talking about: CHKP"
- Typing indicator when AI is processing
- Action cards inline (when AI proposes a change, show Accept/Reject buttons)

**States:** Collapsed (just the toggle button), Open (320px panel), Processing (typing indicator), Error ("Could not connect to AI. Check your API key.")

## Onboarding Flow (new user, first visit)

**Trigger:** No active strategy in DB.

```
Step 1: Welcome
  "Welcome to FundOps. Let's set up your investment strategy."
  [Start] button → opens full-screen conversation

Step 2: Strategy Conversation
  Full-screen conversation mode (no sidebar, no nav)
  AI asks about investing style, horizon, risk, sectors
  Progressive: starts open-ended, follows the thread

Step 3: Confirmation Checkpoint
  "Here's what I understood:"
  Compiled strategy summary (name, north star, dimensions)
```

## Cross-Page Interaction Patterns

**Ticker links:** Every ticker displayed anywhere is a link to `/ticker/:ticker`. Blue/amber monospace text, underline on hover.

**Action buttons:** Primary (amber background, dark text), Secondary (outlined, amber border), Destructive (red outline). All 44px+ touch targets.

**Tables:** Dense, monospace numbers, alternating row background (subtle). Sortable columns with arrow indicators. Sticky headers on scroll.

**Cards:** `--bg-secondary` background, 1px `--border` border, 8px border-radius. No shadows (terminal aesthetic). Colored left border for severity (red=action, amber=warning, green=ok).

**Loading:** Skeleton rows matching the table structure. Never blank. Never "Loading..." text.

**Empty states:** Always include: (1) what this page shows when populated, (2) a primary action to get started, (3) warm but professional tone. Never just "No data."

**Keyboard shortcuts:**
- `Cmd+K` → global search (tickers, memos, research)
- `Cmd+J` → toggle conversation panel
- `Cmd+R` → run screener
- `Esc` → close expanded rows, close conversation panel
