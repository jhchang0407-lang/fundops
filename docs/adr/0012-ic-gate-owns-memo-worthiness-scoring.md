# IC Gate Owns Memo-Worthiness Scoring

IC Gate, not Thesis, owns the formal memo-worthiness scoring for opportunities that have advanced out of Thesis. Thesis remains the worker agent that writes a concise opportunity thesis and return profile; it should explain why the opportunity exists, what return sources may drive upside, what could break the thesis, and why the opportunity deserves IC Review. Thesis may rank completed theses by return profile so the best opportunities reach IC, but it should not produce the final qualitative scores that decide whether Memo spend is justified.

IC Gate owns the judging work. It reads the Completed Thesis, Thesis Return Potential and return components, key Thesis evidence notes, active Constitution, and IC Hurdles, then produces IC Conviction, IC Constitution Fit, IC Data Quality, hard hurdle findings, key risk, verdict rationale, and the IC Verdict. This preserves the product boundary that worker agents create artifacts while gate agents judge whether the next resource-intensive workflow should run.

IC Conviction, IC Constitution Fit, and IC Data Quality should use a measurable IC Gate Scoring Model rather than unsupported free-form prose judgment. These scores should be normalized, componentized, and retained with rationale so IC Review Detail can show a compact evidence snapshot while Company Page, Library, and history surfaces can explain the decision later.

Automated IC Pass uses a two-step decision. Hard IC Hurdles are evaluated first; a confirmed hard-hurdle miss produces IC Fail unless the user manually overrides it in the active IC context. If hard hurdles pass, IC Gate computes an IC Gate Score from IC Conviction, IC Constitution Fit, and IC Data Quality. The default IC Gate Score Blend is 45% IC Conviction, 35% IC Constitution Fit, and 20% IC Data Quality, with a default IC Pass Cutoff of 70/100.

Return Potential remains a Thesis output because it is part of the opportunity and return profile. It should remain a raw expected return percentage with retained return components such as valuation gap, growth, margin expansion, capital returns or dividends, and multiple re-rating when applicable. Thesis Selection Ranking may use this return profile, return-source support, and stable handoff order to decide which completed theses enter Thesis Selection.

Existing implementation payloads and historical artifacts may still include Thesis-level fields named conviction or constitution_fit. Those fields are deprecated for new active Thesis behavior. They should not be displayed as Thesis scores, used by Thesis Selection, or passed forward as worker-agent judgments; equivalent memo-worthiness evidence belongs in Saved IC Verdict Evidence after IC Review runs.

The IC Gate Scoring Model should remain stable across strategies. The active Constitution changes the evidence evaluated inside IC Constitution Fit and supplies IC Hurdles, IC Gate Score Blend, and IC Pass Cutoff, but it should not replace the overall scoring model. IC score component weights should be fixed defaults rather than user-facing configuration. The top-level IC Gate Score Blend is distinct from those internal component weights and may be defined, defaulted, or changed through Strategy Chat as a reviewable Constitution setting.

When an IC score component lacks enough evidence to measure confidently, it should score as neutral 50 rather than zero or being excluded from the average. Missing evidence should primarily lower IC Data Quality instead of automatically destroying IC Conviction or IC Constitution Fit. Contradicted evidence is worse than unknown evidence: a contradicted component should score below neutral, reduce the affected qualitative IC score, and also reduce IC Data Quality.

Hard IC Hurdles remain explicit memo-worthiness gates owned by the active Constitution. A confirmed IC Hurdle Miss should produce an automated IC Fail unless the user manually overrides it for the active IC context. IC Gate may semantically interpret whether a raw signal truly satisfies a hurdle, but it should not waive a confirmed hard-hurdle miss on its own.

Completed IC Verdicts should preserve the evidence snapshot they judged: Completed Thesis reference, Thesis Return Potential and return components consumed, IC Conviction, IC Constitution Fit, IC Data Quality, IC Gate Score, IC Gate Score Blend, IC Pass Cutoff, hard hurdle state, Constitution Version, and short verdict rationale. Exact database schema and storage design for that evidence snapshot are deferred to the database-structure grill.
