# New Architecture Does Not Migrate the Proof-of-Concept Schema

FundOps will treat the current application and database shape as proof-of-concept and ideation work rather than as an MVP schema that must be migrated forward. The new Local FundOps Workspace architecture may start from a clean baseline designed around stable investment identity, canonical evidence, frozen evidence bundles, completed artifact identity, and rebuildable projections.

Forward migrations, repair tools, and compatibility expectations apply after the new architecture baseline exists. They do not require preserving or migrating the current proof-of-concept SQLite tables, payload shapes, UI-specific state, or generated sample data.
