# AI Drafts Strategy Proposals, Deterministic Guardrails Validate

Strategy Chat may draft Strategy Change Proposals with structured fields and prose explanations, but deterministic guardrails must validate criterion ids, value types, ranges, projection compatibility, required explanations, and prose-to-structure consistency before a proposal can become active. We chose this because the AI should help users articulate strategy, but it must not be trusted as the sole authority for machine-executable settings in an investment workflow.
