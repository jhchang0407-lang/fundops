# Canonical Evidence Records Feed Workflows

FundOps will treat source-linked evidence as a shared platform substrate rather than as workflow-local datapoints. Screener, Thesis, IC Review, Memo, Thesis Health, Portfolio, Portfolio Review, Company Page, Archive Q&A, and Learning/Evals should produce and consume Canonical Evidence Records so the same fact, metric, citation, user response, or workflow finding can be reused with provenance instead of copied into separate per-function stores.

Supported Financial Metrics remain the strict typed subset for financial measurements, with cataloged definitions, units, formulas, applicability, and missing-data behavior. The broader evidence layer also includes qualitative findings, filing citations, market research claims, prompt/model outputs worth auditing, portfolio events, user feedback, and workflow judgments, each linked to source, time, confidence or quality signals, and the artifacts or records that used it.
