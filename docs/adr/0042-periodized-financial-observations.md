# Periodized Financial Observations

FundOps will store financial data as periodized Financial Observations rather than only as latest company fundamentals snapshots. Each observation should retain the relevant Investment Entity or Security, Supported Financial Metric, fiscal period, period type, source, as-of and capture timing, unit, currency, whether it is reported, mapped, calculated, estimated, restated, or derived, formula provenance when applicable, quality state, and links to workflows that used it.

Latest financial values for Company Page, Screener, Memo, Thesis Health, Portfolio Review, and other workflows should be projections over these observations. Company Page should be able to review the current financial state while also exposing multi-period annual and quarterly history for trends, full financials, thesis-health checks, memo evidence, and Learning/Evals.
