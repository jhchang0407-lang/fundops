# Typed Evidence Families Share One Contract

FundOps will avoid both extremes of one mushy generic evidence table and fully separate workflow-owned evidence stores. Canonical Evidence Records should share an Evidence Contract for identity, provenance, timing, source, quality, supersession, artifact usage, and workflow links, while major Evidence Families get typed structure for validation and queries.

Initial evidence families should include financial metric observations, filing and source citations, market data observations, qualitative research claims, model-generated findings, user responses and decisions, workflow judgments, and portfolio events. This keeps evidence reusable across capabilities while still letting each family encode the fields that make it trustworthy and useful.
