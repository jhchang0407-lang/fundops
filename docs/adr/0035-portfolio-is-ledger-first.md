# Portfolio Is Ledger-First

FundOps will model Portfolio as an investment ledger rather than as current holdings only. Purchase lots, sale entries, exit records, corrections, valuation marks, and portfolio-linked evidence should be retained as the source records from which current holdings, realized P&L, unrealized P&L, and portfolio review context are projected.

This keeps portfolio history useful for Company Page, Learning/Evals, thesis-health tracking, and later outcome analysis. Current position rows may exist for fast reads, but they are projections over the Portfolio Ledger rather than independent truth.
