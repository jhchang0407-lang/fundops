# Criteria Track Data Support and Proxies

FundOps will let users express custom desired Strategy Criteria, but each criterion must declare its Data Support Level before it can drive deterministic workflow settings. Data Support Level is used for proposal validation and chip-level explanations, not as a Strategy Metadata Panel summary. Unsupported Criteria are preserved in Strategy Preference Memory rather than cluttering the active executable Constitution; vague preferences should trigger clarifying questions about observable signals; suggested examples must come from signals FundOps can actually inspect; Research Review Criteria can influence Thesis or IC Review analysis without becoming automatic screens or gates; and FundOps may propose Proxy Criteria with explicit limitations instead of pretending unavailable data can be evaluated automatically.
