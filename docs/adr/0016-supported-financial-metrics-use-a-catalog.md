# Supported Financial Metrics Use a Catalog

New financial variables and calculations must become Supported Financial Metrics in a canonical Financial Metric Catalog before FundOps relies on them across Screener, Thesis, IC Review, Investment Memo, Thesis Health, Learning/Evals, or Company Page financial display. Supported metrics are globally available to every workflow by default; FundOps should not gatekeep useful metrics from a workflow just because that workflow was not the first surface to use them. Each supported metric needs a definition, source or formula, unit, expected range, sector applicability, comparability, missing-data behavior, and decision authority for hard gates. We chose this over opportunistic per-surface fields because FundOps already spans many evidence consumers, and uncataloged metrics would make screening, explanations, learning, and data-quality behavior inconsistent.

Calculated metrics should retain formula provenance, including inputs, period basis, lookback basis, average-versus-ending-balance choices, sector exclusions, and missing-data behavior. This is especially important for common metrics with multiple valid formulas, such as working-capital days and cash conversion cycle.

Existing useful formulas may remain acceptable first-pass Supported Financial Metrics when their basis is explicit. FundOps should improve formulas where the difference is material, easy to validate, or likely to affect hard gates, but formula refinement should not block broadly useful metrics from being available across workflows with honest provenance.
