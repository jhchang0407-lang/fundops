# One Active Strategy, One Primary Portfolio

FundOps will shape the Local FundOps Workspace around one active Constitution and one primary Portfolio Ledger for the product core. The workspace should preserve immutable Constitution Versions, historical workflow outputs, archived positions, closed lots, portfolio events, and Learning/Evals history, but it should not optimize the baseline product or schema around many parallel active strategies, portfolios, mandates, or account books.

This keeps FundOps focused as a personal investment operating system rather than a multi-fund or multi-account platform. Parallel strategy and portfolio support can be revisited later, but making it a baseline assumption would multiply projections, Dashboard semantics, workflow runs, artifact lookup, and learning interpretation before the product needs that complexity.
