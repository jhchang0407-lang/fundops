# PDF Is the Primary Retail Artifact Export

FundOps will treat polished PDF as the primary user-facing export format for readable completed artifacts. Retail users should be able to export investment memos and other substantial artifacts as well-formatted PDFs suitable for reading, saving, and sharing, rather than receiving raw markdown or a browser print dump.

Markdown may still exist as an internal or supporting representation for rendering, tests, portability, developer workflows, and intermediate artifact snapshots. It should not be the primary retail export format, and PDF generation should come from the structured artifact or a controlled rendered snapshot rather than from re-running the workflow.
