# Stable Investment Identity Beyond Tickers

FundOps will keep the product experience ticker-first while treating ticker symbols as lookup and display aliases rather than permanent database identity. Retained evidence, completed artifacts, portfolio records, and learning records should attach to stable Investment Entity or Security identity when possible, while preserving the observed ticker symbol, source, and time used by the workflow.

The identity model should distinguish Issuers, Securities, Security Listings, Ticker Symbols, and Ticker Alias History. This avoids losing history or misattributing evidence when a company changes ticker, has multiple share classes, trades through ADRs or different listings, changes exchange, or when provider and SEC identities do not map cleanly to the current symbol.
