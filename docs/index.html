How it works

7-Agent Pipeline

Modeled after a real hedge fund. Each agent has exactly one job. The pipeline processes top 20 screened candidates through thesis, sends the best 10 to IC review, and generates memos for those that pass.

SC Screener

Scores a universe of stocks against your strategy. Supports S&P 500, Nasdaq 100, Russell 2000, or custom ticker lists.

TH Thesis

Generates investment thesis with web research, SEC filings analysis, and independent valuation for top 20 candidates.

IC IC Review

Stress-tests each thesis with 70% haircuts for bear case. Only stocks that beat S&P 500 even in the bear case pass.

MM Memo

Full deep-dive research report and strategy-tailored investment memo for IC-passed stocks.

LB Library

Stores all research artifacts, tracks prediction accuracy, and enables natural language search across your archive.

PF Portfolio

Monitors held positions: live P&L, thesis health checks against SEC data, and news-based drift detection.

AL Allocator

Position sizing recommendations, concentration alerts, and buy/trim/exit action items based on your constitution.

Get started

Install in 5 minutes

Requires Python 3.12+ and Node.js 18+. Only an OpenAI API key is needed to start.

# Clone and setup
git clone https://github.com/jhchang0407-lang/fundops.git
cd fundops
cp .env.example .env
# Add your OPENAI_API_KEY to .env

# Backend
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# Frontend
cd frontend && npm install && cd ..

# Run
uvicorn backend.api:app --reload --port 8000 # Terminal 1
cd frontend && npm run dev # Terminal 2

# Open http://localhost:5173
